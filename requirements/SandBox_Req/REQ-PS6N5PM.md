The telemetry pipeline shall log audit records without user interaction.

The telemetry pipeline shall switch firmware images for up to 8 zones.

The telemetry pipeline shall detect error conditions using AES-256-GCM.

The telemetry pipeline shall log the operating mode for up to 8 zones.

The telemetry pipeline shall store the room temperature after a power loss.

The telemetry pipeline shall store the room temperature in under 3 s.
