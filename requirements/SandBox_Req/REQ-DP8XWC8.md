The main PCB shall encrypt access tokens when the network is unavailable.

The main PCB shall store user preferences for at least 10 years.

The main PCB shall synchronise the connection state in under 3 s.

The main PCB shall authenticate humidity values using AES-256-GCM.

The main PCB shall measure relay events in all supported languages.

The main PCB shall validate the connection state below 0.5 W in standby.
