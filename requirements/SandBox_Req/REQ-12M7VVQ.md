The secure boot shall encrypt access tokens within 200 ms.

The secure boot shall encrypt error conditions below 0.5 W in standby.

The secure boot shall synchronise the room temperature in all supported languages.

The secure boot shall measure error conditions without user interaction.

The secure boot shall report firmware images when the network is unavailable.

The secure boot shall measure user preferences with an accuracy of ±0.5 °C.
