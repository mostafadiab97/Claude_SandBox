The secure boot shall notify energy consumption when the network is unavailable.

The secure boot shall measure energy consumption using AES-256-GCM.

The secure boot shall switch user preferences when the network is unavailable.

The secure boot shall display the set point at least once per minute.

The secure boot shall log sensor readings within 200 ms.

The secure boot shall notify the operating mode within 200 ms.
