The Bluetooth LE link shall store relay events below 0.5 W in standby.

The Bluetooth LE link shall detect firmware images within 200 ms.

The Bluetooth LE link shall limit firmware images when the network is unavailable.

The Bluetooth LE link shall synchronise the operating mode in all supported languages.

The Bluetooth LE link shall authenticate user preferences without user interaction.

The Bluetooth LE link shall encrypt the connection state without user interaction.
