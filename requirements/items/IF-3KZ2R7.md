The user account service shall calibrate the connection state below 0.5 W in standby.

The user account service shall display audit records when the network is unavailable.

The user account service shall notify error conditions in under 3 s.

The user account service shall calibrate the connection state when the network is unavailable.

The user account service shall detect the operating mode at least once per minute.

The user account service shall synchronise relay events within 200 ms.
