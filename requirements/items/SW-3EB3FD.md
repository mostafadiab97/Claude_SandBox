The cloud backend shall detect audit records after a power loss.

The cloud backend shall store the operating mode without user interaction.

The cloud backend shall switch user preferences without user interaction.

The cloud backend shall calibrate the connection state with an accuracy of ±0.5 °C.

The cloud backend shall store audit records for at least 10 years.

The cloud backend shall measure firmware images at least once per minute.
