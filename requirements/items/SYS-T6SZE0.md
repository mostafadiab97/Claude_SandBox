The Wi-Fi module shall display access tokens without user interaction.

The Wi-Fi module shall encrypt firmware images within 200 ms.

The Wi-Fi module shall notify the room temperature below 0.5 W in standby.

The Wi-Fi module shall report sensor readings without user interaction.

The Wi-Fi module shall validate relay events below 0.5 W in standby.

The Wi-Fi module shall encrypt relay events without user interaction.
