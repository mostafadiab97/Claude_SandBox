The local API shall report firmware images for at least 10 years.

The local API shall notify relay events for at least 10 years.

The local API shall restore humidity values with an accuracy of ±0.5 °C.

The local API shall measure energy consumption without user interaction.

The local API shall notify relay events below 0.5 W in standby.

The local API shall encrypt firmware images with an accuracy of ±0.5 °C.
