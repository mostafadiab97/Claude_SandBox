The secure boot shall limit the connection state within 200 ms.

The secure boot shall log humidity values after a power loss.

The secure boot shall calibrate error conditions when the network is unavailable.

The secure boot shall synchronise user preferences within 200 ms.

The secure boot shall restore access tokens with an accuracy of ±0.5 °C.

The secure boot shall switch safety limits after a power loss.
