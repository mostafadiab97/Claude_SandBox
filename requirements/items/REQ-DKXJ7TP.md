The OTA server shall restore firmware images for up to 8 zones.

The OTA server shall log sensor readings at least once per minute.

The OTA server shall notify energy consumption within 200 ms.

The OTA server shall validate error conditions in under 3 s.

The OTA server shall measure humidity values with an accuracy of ±0.5 °C.

The OTA server shall store the room temperature in all supported languages.
