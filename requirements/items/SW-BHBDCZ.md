The tamper detection shall log the operating mode without user interaction.

The tamper detection shall authenticate user preferences in all supported languages.

The tamper detection shall report the set point using AES-256-GCM.

The tamper detection shall validate energy consumption without user interaction.

The tamper detection shall encrypt error conditions below 0.5 W in standby.

The tamper detection shall limit user preferences at least once per minute.
