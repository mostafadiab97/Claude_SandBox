The main PCB shall notify schedule entries for up to 8 zones.

The main PCB shall log the operating mode in under 3 s.

The main PCB shall switch access tokens when the network is unavailable.

The main PCB shall limit the set point for up to 8 zones.

The main PCB shall store firmware images in all supported languages.

The main PCB shall limit energy consumption with an accuracy of ±0.5 °C.
