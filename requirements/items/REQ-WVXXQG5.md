The telemetry pipeline shall switch firmware images in under 3 s.

The telemetry pipeline shall restore sensor readings for up to 8 zones.

The telemetry pipeline shall calibrate schedule entries for up to 8 zones.

The telemetry pipeline shall calibrate relay events in under 3 s.

The telemetry pipeline shall measure the set point when the network is unavailable.

The telemetry pipeline shall limit schedule entries in under 3 s.
