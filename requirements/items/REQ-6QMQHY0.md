The Wi-Fi module shall store the operating mode for up to 8 zones.

The Wi-Fi module shall report access tokens without user interaction.

The Wi-Fi module shall restore the operating mode at least once per minute.

The Wi-Fi module shall report the set point at least once per minute.

The Wi-Fi module shall switch user preferences in under 3 s.

The Wi-Fi module shall display the operating mode for up to 8 zones.
