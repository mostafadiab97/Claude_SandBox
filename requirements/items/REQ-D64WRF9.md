The main PCB shall validate safety limits without user interaction.

The main PCB shall store firmware images in all supported languages.

The main PCB shall notify user preferences for at least 10 years.

The main PCB shall authenticate sensor readings after a power loss.

The main PCB shall calibrate humidity values with an accuracy of ±0.5 °C.

The main PCB shall measure error conditions after a power loss.
