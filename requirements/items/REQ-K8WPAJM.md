The Wi-Fi module shall authenticate error conditions within 200 ms.

The Wi-Fi module shall limit user preferences below 0.5 W in standby.

The Wi-Fi module shall validate user preferences with an accuracy of ±0.5 °C.

The Wi-Fi module shall log audit records when the network is unavailable.

The Wi-Fi module shall notify the set point below 0.5 W in standby.

The Wi-Fi module shall display energy consumption in under 3 s.
