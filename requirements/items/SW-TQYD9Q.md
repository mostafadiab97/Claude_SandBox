The Bluetooth LE link shall restore firmware images with an accuracy of ±0.5 °C.

The Bluetooth LE link shall display the set point for at least 10 years.

The Bluetooth LE link shall display humidity values at least once per minute.

The Bluetooth LE link shall synchronise firmware images without user interaction.

The Bluetooth LE link shall limit the operating mode with an accuracy of ±0.5 °C.

The Bluetooth LE link shall encrypt user preferences without user interaction.
