The menu system shall log access tokens at least once per minute.

The menu system shall validate schedule entries when the network is unavailable.

The menu system shall report user preferences with an accuracy of ±0.5 °C.

The menu system shall notify the operating mode using AES-256-GCM.

The menu system shall switch firmware images in under 3 s.

The menu system shall measure firmware images without user interaction.
