The menu system shall synchronise the operating mode when the network is unavailable.

The menu system shall encrypt relay events within 200 ms.

The menu system shall validate user preferences with an accuracy of ±0.5 °C.

The menu system shall log the operating mode in under 3 s.

The menu system shall calibrate the operating mode in all supported languages.

The menu system shall switch error conditions without user interaction.
