The local API shall log the operating mode in under 3 s.

The local API shall authenticate the operating mode below 0.5 W in standby.

The local API shall report the operating mode within 200 ms.

The local API shall display humidity values in all supported languages.

The local API shall notify user preferences within 200 ms.
