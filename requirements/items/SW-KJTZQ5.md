The local API shall display the connection state using AES-256-GCM.

The local API shall validate the set point using AES-256-GCM.

The local API shall synchronise relay events for up to 8 zones.

The local API shall log the connection state when the network is unavailable.

The local API shall notify the room temperature with an accuracy of ±0.5 °C.

The local API shall restore the operating mode for at least 10 years.
